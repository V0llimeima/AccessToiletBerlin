# AccessToiletBerlin.apk

Dieser Ordner enthält die fertig gebaute Android-Anwendung.

## Installation

1. `AccessToiletBerlin.apk` auf ein Android-Gerät herunterladen oder übertragen.
2. Die APK auf dem Gerät öffnen.
3. Falls Android nachfragt, die Installation aus dieser Quelle für den verwendeten Browser oder Dateimanager erlauben.
4. Installation bestätigen.
5. **AccessToilet Berlin** starten.

Voraussetzung: **Android 7.0 (API 24) oder neuer**.

Für Basiskarte und Fußgängerrouting ist eine Internetverbindung erforderlich. Die Toilettendaten sind bereits in der App enthalten.

Die Standortberechtigung wird erst benötigt, wenn in der App **STANDORT** verwendet wird.

## Build-Informationen

- Application ID: `de.bht.accesstoilet`
- Version: `0.1`
- Minimum Android API: 24
- geprüfter Emulator: Pixel 7, Android API 34

Die APK ist der für die Abgabe erzeugte Debug-Build des Projektstands. Andere Android-Geräte wurden nicht systematisch getestet.
